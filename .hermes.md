# Project: YMD (Yandex Music Downloader)

## Identity
Полный нативный Android Kotlin рерайт `yandex-music-downloader-realflac`. Не обёртка над Python — самостоятельное приложение с собственной реализацией API Яндекс.Музыки.

### Phase 2 — Data Layer (4 LLM calls)

**2.1 `generate-api-dtos`**
Output: `data/remote/dto/` — `TrackDto`, `AlbumDto`, `ArtistDto`, `PlaylistDto`, `DownloadInfoDto`, `LyricDto`
Source: structures from `py-ref/ymd/api.py`. All `@Serializable`.

**2.2 `generate-api-client`**
Output: `data/remote/api/YandexMusicApi.kt`, `data/remote/download/DownloadManager.kt`
- Ktor Client: timeout 20s default, retries 20 default, retry delay 5s default (configurable)
- HMAC-SHA256 signing: port from `py-ref/ymd/api.py::DEFAULT_SIGN_KEY`
- URL parsing: port `TRACK_RE`, `ALBUM_RE`, `ARTIST_RE`, `PLAYLIST_RE` from `py-ref/ymd/cli.py`
- Pagination: `FETCH_PAGE_SIZE=10` for playlists
- Filters: `only_music` (skip podcasts/audiobooks), `stick_to_artist` (artist albums only)
- Atomic write: temp file + rename (`write_via_temporary_file` pattern from `py-ref/ymd/core.py`)

**2.3 `generate-decryptor`**
Output: `data/remote/download/Decryptor.kt`
- Port `decrypt_data()` from `py-ref/ymd/api.py`
- `javax.crypto.Cipher` AES/CTR/NoPadding (replaces `pycryptodome` AES-CTR)

**2.4 `generate-database`**
Output: Room entities+DAOs (DownloadHistory, TrackCache), `datastore/SettingsDataStore.kt`, `datastore/TokenDataStore.kt`, `security/CryptoManager.kt`
- Tokens: Android Keystore + EncryptedSharedPreferences
- DataStore Preferences for all app settings
- Auto Backup for Apps support in Manifest

**After:** verify compile → commit `"feat: data layer"`

### Phase 3 — Domain Layer (2 LLM calls)

**3.1 `generate-domain-models`**
Output: `domain/model/` — `Track`, `Album`, `Artist`, `DownloadTask`, `DownloadQuality` (enum: LOW=0/MED=1/BEST=2), `LyricFormat` (enum: NONE/TEXT/LRC), `PathPattern`

Output:
- `domain/usecase/` — `StartDownloadUseCase`, `GetTrackInfoUseCase`, `ParseUrlUseCase`, `SearchTrackUseCase`
- `domain/util/PathPatternParser.kt` — placeholders: `#number`, `#track-artist`, `#album-artist`, `#title`, `#album`, `#year`, `#artist-id`, `#album-id`, `#track-id`, `#number-padded`; default: `#album-artist/#album/#number - #title`; optional unsafe mode (skip char sanitization)
- `domain/util/MimeTypeGuesser.kt` — port from `py-ref/ymd/mime_utils.py`
- `domain/util/TagWriter.kt` — MP3 (ID3 via jaudiotagger), MP4, FLAC (vorbis-java); port `set_tags()` from `py-ref/ymd/core.py`

**After:** verify compile → commit `"feat: domain layer"`

- Embed cover: Switch
- Cover resolution: Slider 100–4000 + TextField (accepts "original")
- Request delay: Slider 0–10s
- Only music: Switch (skip podcasts/audiobooks)
- Stick to artist: Switch (show only when artist URL detected)
- Compat level: Slider 0–1
- Advanced (expandable card): timeout Slider 1–120s, retries Slider 0–50 (0=∞), retry delay Slider 0–30s
- Save path: SAF Directory picker + path pattern TextField with placeholder hints + unsafe path Switch

## Operation Rules
1. Terminal ops (git, gradle, mkdir, file writes): Hermes only — no LLM
2. LLM: code generation and complex bug fixes only
3. Never recreate the session mid-project (prompt cache invalidation)
4. One logical group per LLM call (max 3 files)
5. Reference previous LLM responses via context, not full re-paste
6. Missing system tool → report to user immediately: `"Need: sdkmanager 'platforms;android-37.0'"`; don't block — add TODO and continue
7. Commit after every phase with descriptive message
