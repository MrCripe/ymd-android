# YMD Android — Yandex Music Downloader

> **⚠️ NOTE: This project was generated by AI (OpenAI / Google / similar). The code may contain errors. Use at your own risk.**

Android app for downloading music from Yandex Music. Fork of [yandex-music-downloader](https://github.com/...) — rewritten in Kotlin with Jetpack Compose.

## 🚀 Quick Start

### 1. Getting API Key (GitHub Personal Access Token)

To build the project, you need a GitHub Personal Access Token (PAT):

1. Go to https://github.com/settings/tokens
2. Click **Generate new token**
3. Select scope: **Contents (Read and write)**
4. Generate the token
5. Copy the token

### 2. Getting Yandex Music Token

1. Go to https://music.yandex.ru
2. Open DevTools (F12) → Application → Cookies
3. Copy the `music_token` cookie value (starts with `y0_`)
4. Or use a test token from Yandex Music documentation

### 3. Build

```bash
git clone https://github.com/MrCripe/ymd-android.git
cd ymd-android

# Create local.properties
echo "sdk.dir=/path/to/Android/Sdk" > local.properties

# Build
./gradlew :app:assembleDebug

# Install on device
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## ⚠️ Known Bugs

- **Cover art not embedded** in MP4/M4A files — cover URL requires replacing `%%` with `orig`, but jaudiotagger embedding is unstable
- **Lyric files (LRC)** not downloaded or embedded — feature not implemented
- **FLAC inside MP4** (flac-mp4) not supported — jaudiotagger cannot handle FLAC in MP4 container
- **Some tracks** may not download due to regional restrictions
- **API signing** requires correct User-Agent (Android UA used instead of API UA)
